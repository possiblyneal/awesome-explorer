# Glossary

- **Operator** — the person running the explorer and reading its results; also its only user.
- **Awesome list** (or **list**) — a GitHub repository whose README curates links to other repositories.
- **Index** — `sindresorhus/awesome`, the list of awesome lists the explorer starts from.
- **Entry** — one repository a list links to, with the section and description the list gives it.
- **Discovery** — a GitHub search for awesome lists, flagging those the index leaves out. A result outside the index counts as a list only when its README has 50+ distinct outbound links.
- **Stars** — the operator's starred repositories, explored like a list's entries.
- **Trending** — GitHub's trending pages for every followed period, coding language, and spoken language, merged and ranked by stars gained per day, minus stars and hidden repositories.
- **Dismiss** / **snooze** — hide a trending repository for good, or for 30 days; either can be undone right after.
- **Social preview** — the image a repository's owner uploads to represent it. Trending shows it when one exists; a repository without one has none, since GitHub's generated card only repeats the name and description.
- **Metrics** — the numbers fetched for an entry: stars, recent stars, commits, issues, pull requests, and response times.
- **Health label** — the verdict on an entry: `mature`, `rising`, `active`, `stale`, or `dead`. Its **health score** (0–100) ranks entries within and across labels.
